# Guía 04 - Peticiones GET y POST con Fetch

Este proyecto es la solución a la Guía de Laboratorio #04 de JavaScript, enfocado en el uso de la API `fetch` para consumir una API REST (JSONPlaceholder).

## Características
- **GET:** Listado de publicaciones con filtro por título y límite de resultados seleccionable.
- **GET (Comentarios):** Carga dinámica de comentarios al hacer clic en una publicación.
- **POST:** Creación de nuevas publicaciones con validación de formulario.
- **POST (FormData):** Creación de comentarios construyendo el cuerpo con `FormData` y `Object.fromEntries`.

## Tecnologías usadas
- HTML5
- CSS3
- JavaScript (Vanilla)
